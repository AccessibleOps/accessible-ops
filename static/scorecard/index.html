The Accessible Ops factors, in practice

Who clears the factors today

The factors set a bar for infrastructure you can hand to a newcomer, human or agent. Clearing them takes work in three places: synthesis, turning source into the platform's native spec before anything runs; ops, how a change reaches production; and lifecycle, the approval, rollback, and record around it.

This is a snapshot of which tools clear which factors right now. chant clears the whole list first, but the checks aren't chant's to keep — each one names a property any tool can earn, and the others are moving. The bar is the spec described on this site.

Synthesis

Source becomes the platform's own spec, worked out from the text and settled before anything is touched.

Ops

A change reaches production as one reviewable diff, scoped to what it declares.

Lifecycle

The risky call waits for a human, the reversible one runs, and every change leaves a record.

Read down the columns and the shape is a division of labor, not a ranking. The config languages clear synthesis and stop there: they are values, not operators, so the ops and lifecycle band is out of scope and you assemble it yourself. CDK and Pulumi own operations but run your program to get there, so the spec doesn't exist until execution. Terraform and OpenTofu operate through a state file, and their real check is a cloud plan that lands after the commit.

chant reaches every row because it folds source to the native spec by construction, then carries that same change set through approval, rollback, and a record. It got there first. The columns are wide on purpose — there is room for more of them, and nothing here is chant's to keep.

Notes

  1. Scoping and revocation are provider-native (OIDC expiry, IAM). A tool's part is to reference a secret by name and never hold it, and to flag over-broad permissions at author time.
  2. Rotation is cheap as a consequence, not a command. When a secret enters only by reference and never lands in source or state, rotating the underlying credential is an out-of-band change the source never sees.
  3. Formae (Pkl-based) adds a reconcile loop and lifecycle, but authors in a config DSL and keeps a state database, so it sits with the config-language band on synthesis and carries the state the folded tools drop.
  4. “Folds by construction” means synthesis reduces the source to spec with no module execution — a call-as-value is structurally unrepresentable, and the semantic lint is a pre-flight diagnostic rather than the guarantee.
The factors are the spec on this site. This scorecard reads the common tools against them, and will age as they change.
